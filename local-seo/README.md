# Local SEO

Local SEO skills for businesses that win clients from their own neighborhood: the Google Business Profile, consistent business details everywhere, and reviews that turn searchers into bookings.

## Skills

| Skill | What it does |
| --- | --- |
| gbp-optimization | Optimize a Google Business Profile: categories, services, photos, posts, Q&A, and NAP consistency. |
| review-management | Get more reviews, answer them well, and use them on the website as proof. |

## Commands

| Command | What it does |
| --- | --- |
| /local-seo:gbp-check | Checks a business's GBP and local presence and lists the fixes. |

## Usage

```
/local-seo:gbp-check Radiance Med Spa, Fort Worth TX
```

The check reviews the profile as a searcher sees it, compares the business details across the website and directories, and returns a ranked fix list.
