# AI Search

Skills for making a local business the answer Google shows and the source AI engines cite.

Search is no longer only a list of links. Clients get their answer straight from a featured snippet, a voice assistant, ChatGPT, Perplexity, or a Google AI Overview. If the business is not in that answer, it is not in the choice at all. These skills cover the full loop: structure content so answers can be lifted, build the trust that makes AI engines cite the business, and measure whether it is actually showing up.

## Skills

| Skill | What it does |
| --- | --- |
| aeo | Answer Engine Optimization: featured snippets, People Also Ask, and voice answers. |
| geo | Generative Engine Optimization: getting cited by ChatGPT, Perplexity, and Google AI Overviews. |
| ai-rank | Measuring visibility inside AI answers with prompt tests and a recorded baseline. |

## Commands

| Command | What it does |
| --- | --- |
| /ai-search:ai-rank-test | Tests a business's AI search visibility with a set of prompts and records the baseline. |

## Usage

Test a med spa's AI visibility before doing any optimization work, so the fixes can be measured against a real baseline:

```text
/ai-search:ai-rank-test Radiance Med Spa, Fort Worth
```

Then use the `geo` skill to fix what the test exposes, and the `aeo` skill to shape the pages so answers can be lifted. Re test weekly with the same prompts.
