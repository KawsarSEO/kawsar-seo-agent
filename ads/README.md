# Ads

Paid ads for local service businesses. Catch buyers already searching on Google, and put an offer in front of the right audience on Facebook and Instagram.

## Skills

| Skill | What it does |
| --- | --- |
| google-ads | Plan Google Ads: campaign structure, keywords and match types, ad copy, landing page match, location targeting |
| facebook-ads | Plan Facebook and Instagram ads: audience targeting, ad copy, creative ideas, lead forms, retargeting basics |

## Commands

| Command | What it does |
| --- | --- |
| `/ads:ad-copy` | Write ad copy variants for a service and an offer |

## Usage

```
/ads:ad-copy Google Ads, HydraFacial in Fort Worth, first visit $99, book now
```

The command returns two ad variants with headlines and descriptions, plus a note on which search each one fits.
