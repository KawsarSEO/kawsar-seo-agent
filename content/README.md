# Content

Skills for writing content that ranks on Google, gets cited by AI search, and reads like a person wrote it.

Good content for a local business does one job: it answers the question a client is asking, proves the business can be trusted, and makes the next step obvious. These skills cover the three kinds of writing a local business needs most: pages that rank, rewrites that sound human, and social posts that help instead of selling.

## Skills

| Skill | What it does |
| --- | --- |
| seo-content-writing | Service pages, local pages, and blog posts built on search intent. |
| human-content | Rewrites AI sounding text into natural, human content without losing the facts or the SEO value. |
| social-media-content | Helpful, not salesy posts, captions, and reel scripts for local service businesses. |

## Commands

| Command | What it does |
| --- | --- |
| /content:write-page | Writes a ready to publish service page for a treatment and city. |

## Usage

Write a service page for a treatment and a city, ready to publish with title, headings, meta description, and FAQ:

```text
/content:write-page Lip Filler, Fort Worth
```

If a draft already exists but reads like AI wrote it, run it through the `human-content` skill before publishing. For the same topic on social media, use the `social-media-content` skill to turn the page into a helpful post or reel script.
