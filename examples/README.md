# Examples

Sample outputs from the skills in this repo. Each sample shows the file shape a real skill run produces, so you can see what you will get before you run a skill.

## Samples

* `seo-audit-sample/TECH-AUDIT.md`: a full technical SEO audit with a 0 to 100 weighted score, a top 10 fix list ranked by priority score, and findings per section.
* `ai-visibility-sample/REPORT.md`: an AI visibility report with a citation heatmap across ChatGPT, Perplexity, and Google AI Overviews, topic clusters, a competitor comparison, and 5 prioritized actions.

## Important note

Both samples are fictional. The business (Northwind Med Spa), the domain (northwind-medspa.example), the city (Maple Falls), the competitors, and every number in them are invented for demonstration only. No data in these files describes a real business.

Real skill runs produce the same file shapes for real businesses, with real measured data in place of the invented sample data.
